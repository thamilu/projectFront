# E-Shop: Enterprise eCommerce Platform

An ultra-premium, high-performance eCommerce frontend built with **Next.js 16**, **React 19**, and **Tailwind CSS 4**.

## 🛡️ Enterprise Engineering Standards

This project is hardened against the **[HARDEN]** rule, ensuring pixel-perfect UI, strict type safety, and modular scalability.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run full validation (Lint, Type-check, Test)
npm run validate
```

## 🛠️ Technology Stack

- **Framework**: Next.js 16 (App Router)
- **Runtime**: React 19
- **Styling**: Tailwind CSS 4 + shadcn/ui
- **State**: Zustand + TanStack Query
- **Auth**: NextAuth + Keycloak
- **API**: Spring Boot 4 (Backend)
